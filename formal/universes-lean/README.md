# Kappa universe soundness formalization

This standalone Lean 4 project develops a mechanized assurance case for the universe machinery specified in
[`docs/Spec.md`](../../docs/Spec.md) §§11.1–11.1.3 and §30.2.2.9. The specification is authoritative; this project does
not weaken its model to match the currently incomplete Haskell implementation.

## What is proved now

The initial model gives the rigid canonical level grammar semantic values of the form `ω·n + k`, which are exactly the
closed ordinals generated by Kappa's `0`, `ω`, successor, ordinal addition, and maximum operations. It proves:

- ordinal addition has the specified direction (`1 + ω = ω`, while `ω + 1 ≰ ω`);
- `succ u ≰ u` for every level, including open expressions under every valuation;
- cumulative universe typing validates `Type u : Type (succ u)` but cannot validate `Type u : Type u`;
- a satisfiable set of local erased proof-bound assumptions cannot entail self-containment;
- no level is an automatic top/ceiling, so `ω` cannot silently cap an unbounded telescope;
- the safe parametric capability relation permits ordinary-code-to-witness use but has no witness-to-code promotion.

These results block the `Type : Type` premise used by the Girard-style construction at the universe-kernel boundary.
They are not yet a proof of normalization or logical consistency for the full Kappa core calculus.

The second proof layer now also establishes:

- universe metavariables have a syntax separate from rigid semantic levels;
- single-meta substitution agrees with semantic valuation update;
- assignments are rejected when the metavariable occurs in its own right-hand side;
- every assignment returned by the checked assignment API satisfies its equation;
- ordered solver-state extensions preserve every earlier equation and produce a model of the enlarged state;
- normalization is denotation-preserving and idempotent, both before and after metavariables are solved;
- the closed constraint fragment is decided by computation, with proofs for both accepted and rejected results;
- every open constraint certificate accepted by the certificate kernel is a valid semantic entailment;
- fuelled structural search returns only certificate-kernel derivations and is therefore sound by construction;
- structural search returns `none` for self-containment whenever the local assumptions are satisfiable;
- no such certificate can derive self-containment from satisfiable assumptions.

The full open-expression decision procedure required by §11.1.2.1 is not yet implemented. In particular, completeness
for arbitrary assumptions involving variables, ordinal addition, and maximum remains an explicit proof obligation.

The dependent-formation layer additionally proves:

- a universe ceiling is accepted only when it excludes all telescope-local level variables;
- an erased `i < κ` assumption bounds the classifier `succ i` by outer `κ`;
- an erased `i ≤ κ` assumption bounds that classifier by `succ κ`;
- for every proposed outer ceiling expression, a countervaluation setting `i` to its value refutes `succ i ≤ κ`;
- consequently `(i : TypeLevel) -> Type i` has no valid ceiling, including `ω` or any successor of `ω`;
- accepted Pi formation produces `max α κ`, remains outer-scoped, and bounds both domain and codomain;
- parametric universe binders perform the no-bump rule while retaining the capability theorem forbidding
  witness-to-code promotion.

The first KCore layer now provides:

- intrinsically scoped syntax: `Core n` can mention only variables in a context of size `n`;
- scope-preserving renaming, weakening, lifted substitution, and dependent-body instantiation;
- typing rules for variables, predicative sorts, ordinary and parametric Pi types, lambdas, dependent application,
  and cumulative universe lifting;
- capability-aware dependent Sigma types, pairing, and first/second projections;
- the exact judgment `(0 t : Type0, a : t) : Type0`, generalized to every `rho` as
  `(0 t : Type rho, a : t) : Type rho`;
- projection preservation: the first projection remains a parametric witness, the second projection has that witness
  as its dependent type, and the first projection cannot be used as ordinary type code;
- capability evidence as a mandatory premise of application typing, rather than a separate advisory check;
- general typing preservation under every context-compatible renaming, including under dependent binders;
- typing weakening as a corollary, with capability-safe use and non-use preserved exactly by renaming;
- general typing preservation under capability-compatible substitution and the dependent substitution lemma;
- substitution permits ordinary code to replace a parametric witness but cannot perform the forbidden reverse;
- sort regularity: every checked classifier of `Type u` is at least `succ u`;
- a KCore-level proof that `Type u : Type u` is impossible;
- proofs that neither an abstract parametric witness nor a parametric context variable can be used as ordinary type
  code, while ordinary code may instantiate a parametric binder.

This proves the critical local fact behind the intended Girard defense: small dependent-pair formation does not imply
`Type rho : Type rho`, and unpacking the pair does not promote its hidden witness to ordinary code. Renaming and
weakening and dependent substitution now preserve typing and the capability boundary. Beta/Sigma reduction
preservation and normalization for this KCore fragment remain stage-4 obligations; full logical consistency is still
the stage-5 result.

## Build

The project is dependency-free beyond Lean itself and pins its toolchain:

```sh
cd formal/universes-lean
lake build
```

## Layout

- `KappaUniverses/Level.lean`: canonical syntax and ordinal semantics.
- `KappaUniverses/Meta.lean`: metavariables, substitution, occurs checks, and checked assignments.
- `KappaUniverses/State.lean`: triangular solver states and model-preserving ordered extension.
- `KappaUniverses/Normalize.lean`: sound and idempotent normalization for rigid and metavariable syntax.
- `KappaUniverses/Soundness.lean`: assumptions, entailment, predicative sort typing, and no-self-containment theorems.
- `KappaUniverses/Solver.lean`: sound certificates, closed decisions, and fuelled structural search.
- `KappaUniverses/Formation.lean`: telescope ceilings, unbounded rejection, Pi formation, and parametric no-bump safety.
- `KappaUniverses/Core.lean`: intrinsically scoped KCore syntax, dependent typing, and capability-checked application.
- `KappaUniverses/Capability.lean`: the parametric-witness capability boundary.
- `KappaUniverses/Examples.lean`: executable/specification examples.
- `PROOF_PLAN.md`: the path from this kernel result to a full consistency and implementation-refinement result.
