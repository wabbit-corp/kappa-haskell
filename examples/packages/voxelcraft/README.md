# Voxelcraft

Voxelcraft is a native Kappa voxel-world starter in the shape of a small
Minecraft-like clone. It includes deterministic terrain, a block palette, chunk
storage, face-mesh accounting, a game entrypoint, and an SDL3 windowed renderer
boundary with Linux Vulkan and macOS Metal-oriented targets.

The renderer shim intentionally uses a conservative C ABI. Kappa owns world
generation, smoothed terrain, fixed-point player/camera updates, visible-face
mesh emission, and the frame loop. SDL3 owns only the native window, input
polling, mouse capture, and drawing backend. On macOS the SDL work is proxied to
a tiny helper process so AppKit event pumping stays on the main thread while
Kappa keeps driving the game state.

## Targets

```text
voxelcraft-tests              pure terrain and mesh tests
voxelcraft-vulkan-linux       Linux game target, prefers Vulkan
voxelcraft-metal-macos-arm64  macOS arm64 game target, prefers Metal
```

## Build

From the repository root:

```sh
cabal run -v0 kappa -- build --manifest examples/packages/voxelcraft --target voxelcraft-tests -o /tmp/voxelcraft-tests
/tmp/voxelcraft-tests
```

Game targets:

```sh
cabal run -v0 kappa -- build --manifest examples/packages/voxelcraft --target voxelcraft-vulkan-linux -o /tmp/voxelcraft
cabal run -v0 kappa -- build --manifest examples/packages/voxelcraft --target voxelcraft-metal-macos-arm64 -o /tmp/voxelcraft
```

The game target requires SDL3 development files visible to `pkg-config`. On
macOS with Homebrew:

```sh
brew install sdl3
```

If you edit `native/voxel_renderer.*`, rebuild once with `--update` so
`kappa.lock` records the new host-binding identity.

## Controls

```text
W/A/S/D       walk and strafe
Left/Right    turn
Up/Down       look up/down
Click window  capture/lock mouse
Mouse motion  turn and look while captured
Esc           release mouse; quit when already released
Space/E       float up
Q             float down
Left Shift    move faster
```

The game executable opens a window, renders a first-person blocky terrain view,
and overlays the selected SDL renderer backend, player position, and live mesh
counts generated by Kappa.
